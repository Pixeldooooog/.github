## About

I make things because language is too slow,  
and reality rarely explains itself.

Most days I write code.  
Some days I dismantle ideas until only the necessary parts remain.  
The rest of the time, I stay suspicious of certainty.

I like:

- products with a pulse
- interfaces that feel inevitable
- clean logic with emotional weight
- people who still ask *why*

---

## Now

- building quietly
- deleting more than adding
- chasing sharp taste over loud output
- trying to make technology feel less empty

## Belief

> The world is crowded with noise, urgency, and performance.  
> I prefer signal. Structure. Motive.  
> If something must exist, it should justify its existence.

## Working Style

I am interested in:

- thoughtful software
- strange but precise visual taste
- human-centered tools

Not interested in:

- fake innovation
- decorative complexity
- optimism as branding
- shipping nonsense faster
